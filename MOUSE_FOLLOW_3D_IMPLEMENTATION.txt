# Mouse Follow 3D Effect Implementation - Contact Form

## Overview

Successfully implemented an interactive Mouse Follow 3D Effect for the "Get In Touch" contact form on the home page. The form now tilts and rotates based on mouse movement, creating an engaging, premium user experience.

---

## 🎯 What Was Implemented

### 1. **useMouseFollow3D Hook**
**File**: `src/hooks/useMouseFollow3D.ts`

**Purpose**: Calculates 3D rotation based on mouse position relative to element

**Features**:
- Tracks mouse movement in real-time
- Calculates rotation angles on X and Y axes
- Returns transform string ready for CSS
- Configurable intensity and max rotation

**Parameters**:
```typescript
interface UseMouseFollow3DOptions {
  intensity?: number;      // 0-1, how much to tilt (default: 0.5)
  maxRotation?: number;    // max degrees (default: 15)
}
```

**Return Value**:
```typescript
{
  ref: RefObject<HTMLDivElement>,
  rotation: { x: number, y: number },
  transform: string  // CSS transform ready to use
}
```

**How It Works**:
1. Listens to `mousemove` events on the element
2. Calculates mouse position relative to element center
3. Converts position to rotation angles (0 to maxRotation)
4. Updates rotation state for smooth animation
5. Returns to center (0, 0) on `mouseleave`

---

### 2. **MouseFollow3DContainer Component**
**File**: `src/components/MouseFollow3DContainer.tsx`

**Purpose**: Wrapper component that applies 3D mouse follow effect to children

**Props**:
```typescript
interface MouseFollow3DContainerProps {
  children: ReactNode;
  className?: string;      // CSS classes for styling
  intensity?: number;      // Tilt intensity (0-1)
  maxRotation?: number;    // Max rotation degrees
}
```

**Features**:
- Wraps any content with 3D effect
- Preserves 3D transforms
- Smooth 100ms transitions
- Easy to reuse on other elements

**Implementation**:


## ✨ Visual Effects

### How It Looks:
1. **Hover Over Form**: Form tilts toward your cursor
2. **Move Cursor**: Form follows your mouse smoothly
3. **Leave Form**: Form smoothly returns to neutral position
4. **Result**: Premium, interactive 3D card effect

### Transform Calculation:
```
rotateX = -(mouseY / elementHeight) * maxRotation * intensity
rotateY = (mouseX / elementWidth) * maxRotation * intensity

Apply: perspective(1000px) rotateX(${x}deg) rotateY(${y}deg)
```

## 🚀 Technical Details

### Mouse Event Flow:
```
1. User moves mouse → mousemove event
2. Calculate mouse position relative to element
3. Convert position to rotation angles
4. Update state with new rotation
5. CSS transform re-renders component
6. Smooth 100ms transition animates to new position
7. User moves away → mouseleave event
8. Set rotation back to 0 degrees
9. Smooth return animation
```

### State Management:
```typescript
const [rotation, setRotation] = useState({ x: 0, y: 0 });

// Updates on every mousemove
setRotation({ x: rotateX, y: rotateY });

// Returns to center on mouseleave
setRotation({ x: 0, y: 0 });
```
