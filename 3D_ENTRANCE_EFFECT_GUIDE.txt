# 3D Entrance Effect - Implementation Guide

## Overview

A professional 3D entrance animation has been implemented that triggers when the website opens. The effect creates an impressive visual impact with 3D transforms and perspective effects.

## What's Implemented

### 1. **CSS Animations** (`src/styles/animations.css`)

Three different 3D entrance effects:

#### `entrance3D` - Main Effect
- Rotates the content from X=90° to 0°
- Applies perspective and depth with translateZ
- Duration: 1.2 seconds
- Creates a flipping effect as if the page is rotating into view

```css
@keyframes entrance3D {
  0% {
    opacity: 0;
    transform: perspective(1200px) rotateX(90deg) rotateY(0deg) rotateZ(0deg) translateZ(-500px);
  }
  100% {
    opacity: 1;
    transform: perspective(1200px) rotateX(0deg) rotateY(0deg) rotateZ(0deg) translateZ(0px);
  }
}
```

#### `entrance3DFlip` - Alternative Flip Effect
- More pronounced 3D flip animation
- Combines Y-axis rotation with scale
- Duration: 1.5 seconds
- Good for hero sections

#### `entrance3DZoom` - Zoom Effect
- Combines 3D perspective with zoom
- Shorter animation (1 second)
- Good for fast, impactful entrances

### 2. **Animation Utility Classes**

```css
.animate-entrance-3d          /* Main 3D entrance */
.animate-entrance-3d-flip     /* Alternative flip effect */
.animate-entrance-3d-zoom     /* Zoom with perspective */

/* Staggered entrance for multiple elements */
.entrance-stagger-1  /* 0ms delay */
.entrance-stagger-2  /* 100ms delay */
.entrance-stagger-3  /* 200ms delay */
.entrance-stagger-4  /* 300ms delay */
.entrance-stagger-5  /* 400ms delay */
```

### 3. **React Hook** (`src/hooks/useEntranceAnimation.ts`)

`useEntranceAnimation()` - Custom hook that:
- Automatically applies 3D entrance animation to main content
- Staggered animation for hero section elements
- Runs on component mount
- Cleanup on unmount
- No parameters needed

```tsx
import { useEntranceAnimation } from "@/hooks/useEntranceAnimation";

export default function Page() {
  // Apply entrance animation on load
  useEntranceAnimation();

  return (
    // Content will automatically animate in
  );
}
```

### 4. **Integration** (`src/app/page.tsx`)

The hook is called in the Home page component:

```tsx
export default function Home() {
  useEntranceAnimation();  // Triggers on page load
  
  return (
    // Page content with 3D entrance effect
  );
}
```

## How It Works

### On Page Load:
1. Main content starts with opacity 0 and rotated 90° on X-axis
2. Over 1.2 seconds, it rotates back to 0° with smooth perspective
3. Hero section elements stagger in with 100ms delays
4. Creates a "page flipping in" visual effect

### Animation Timeline:
- **0ms**: Main content hidden, rotated away
- **600ms**: Halfway through animation - partially visible, partially rotated
- **1200ms**: Animation complete - content fully visible and in place

## Customization

### Change Animation Duration

In `src/hooks/useEntranceAnimation.ts`, modify the animations.css keyframes:

```css
/* Default: 1.2s */
.animate-entrance-3d {
  animation: entrance3D 1.2s ease-out forwards;  /* Change 1.2s to desired duration */
}
```

### Change Animation Type

Replace the animation class in the hook:

```ts
// In useEntranceAnimation.ts
mainElement.classList.add("animate-entrance-3d-flip");  // Use flip instead
// or
mainElement.classList.add("animate-entrance-3d-zoom");  // Use zoom instead
```

### Add Animation to Other Pages

```tsx
import { useEntranceAnimation } from "@/hooks/useEntranceAnimation";

export default function OtherPage() {
  useEntranceAnimation();  // Add this line to any page
  
  return (
    // Content will have 3D entrance effect
  );
}
```

### Adjust Stagger Timing

In `animations.css`, modify the delay:

```css
.entrance-stagger-2 {
  animation-delay: 0.2s;  /* Change to desired delay */
}
```

### Remove from Specific Pages

Simply don't call `useEntranceAnimation()` on pages where you don't want the effect.

## Troubleshooting

### Animation not appearing
- Check browser console for errors
- Verify animations.css is imported in layout.tsx
- Check that useEntranceAnimation() is called
- Ensure no conflicting CSS classes

### Animation feels jerky
- Check if GPU acceleration is enabled in browser
- Verify no heavy computations during animation
- Check DevTools Performance tab for jank
- Consider reducing animation duration

### Animation too fast/slow
- Modify duration in animations.css (default: 1.2s)
- Adjust easing function (default: ease-out)
- Add or remove animation-delay values

### Not working on mobile
- Ensure `@supports (perspective: 1000px)` is supported
- Check mobile browser DevTools for errors
- Test on actual device vs. Chrome DevTools
